What to expect when it is working: the GPU string becomes Mozilla, the canvas and audio hashes differ from the un-damped run (and differ again on a different site), battery reads full, cores read 8, window position reads 0, and the notification prompt resolves to default without ever showing a dialog. Reload twice with the extension on — the hashes should stay identical between reloads. Stability is the point; a hash that changes every reload is itself a tracking signal.
ClientRects and locale/timezone changes are opt-in; enable those switches separately. Compare exact rect hashes, not just rounded dimensions. Local-font probes remain unprotected: a missing-font document.fonts.check() result of true is normal, not proof the font exists. A failed FontFace(local(...)).load() can mean absent or blocked by the browser. All probes stay on this page.
